SETSCOPE · PRIVACY

นโยบายความเป็นส่วนตัว

ปรับปรุงล่าสุด 13 ตุลาคม 2569

นโยบายนี้อธิบายข้อมูลที่ SETscope ใช้ วัตถุประสงค์ ผู้รับข้อมูล ระยะเวลาเก็บ และช่องทางใช้สิทธิของผู้ใช้ โปรดอ่านก่อนสมัครสมาชิก

1. ผู้ดูแลข้อมูลและช่องทางติดต่อ

ผู้ดูแลบริการ SETscope เป็นผู้รับผิดชอบการใช้ข้อมูลตามที่ระบุในนโยบายนี้ ช่องทางติดต่อผู้ดูแลเพื่อขอเข้าถึง แก้ไข หรือลบบัญชี: โปรดระบุอีเมลติดต่อจริงก่อนเปิดเว็บให้บุคคลทั่วไปใช้งาน

2. ข้อมูลที่ใช้และวัตถุประสงค์

  • อีเมลและข้อมูลบัญชี: สมัครสมาชิก ยืนยันตัวตน เข้าสู่ระบบ และดูแลความปลอดภัยบัญชี โดยระบบยืนยันตัวตนจัดการผ่าน Supabase Auth
  • การยอมรับเงื่อนไข: บันทึกเวลาที่สมัครและเวอร์ชันเงื่อนไข เพื่อเก็บหลักฐานการสมัครและดูแลบริการ
  • Watchlist การตั้งเตือน ธีม และประวัติการแจ้งเตือน: จัดเก็บในพื้นที่จัดเก็บของเบราว์เซอร์ที่ใช้งาน เพื่อให้เว็บจำการตั้งค่าบนอุปกรณ์/เบราว์เซอร์นั้น
  • โทเค็นเซสชัน: เก็บชั่วคราวใน session storage ของแท็บเพื่อคงสถานะเข้าสู่ระบบ และส่งให้เซิร์ฟเวอร์ยืนยันสิทธิการเรียกข้อมูล
  • ข้อมูลการใช้งานระบบ: เซิร์ฟเวอร์และผู้ให้บริการโฮสติ้งหรือยืนยันตัวตนอาจบันทึกข้อมูลทางเทคนิค เช่น IP address เวลา คำขอ และเหตุขัดข้อง ตามการตั้งค่าของผู้ให้บริการ

3. ฐานและความจำเป็นในการใช้ข้อมูล

ข้อมูลบัญชีและโทเค็นจำเป็นต่อการสร้างบัญชีและให้บริการสมาชิก หากไม่ให้ข้อมูลดังกล่าวจะไม่สามารถเข้าสู่ระบบได้ ส่วนการบันทึกการยอมรับเงื่อนไขและข้อมูลความปลอดภัยใช้เพื่อดูแลบัญชีและตรวจสอบการใช้งาน ทั้งนี้ผู้ดูแลควรทบทวนฐานการประมวลผลให้ตรงกับการใช้งานจริงก่อนเปิดให้บริการ

4. ผู้ให้บริการภายนอกและการเปิดเผย

อีเมลและข้อมูลบัญชีถูกส่งไปยัง Supabase เพื่อยืนยันตัวตนและจัดการบัญชี ข้อมูลคำขอราคาหุ้นและข่าวถูกส่งจากเซิร์ฟเวอร์ไปยัง Yahoo Finance และ Google News ส่วนกราฟ TradingView เป็นวิดเจ็ตจากผู้ให้บริการภายนอกที่โหลดในเบราว์เซอร์ SET API อาจถูกใช้สำหรับมูลค่าซื้อขายเมื่อผู้ดูแลตั้งค่า การใช้งานบริการเหล่านี้อยู่ภายใต้นโยบายของผู้ให้บริการแต่ละราย และอาจประมวลผลข้อมูลบนระบบหรือภูมิภาคที่ผู้ให้บริการกำหนด

5. ระยะเวลาเก็บและการลบ

ข้อมูลบัญชีเก็บไว้ขณะบัญชียังใช้งานหรือเท่าที่จำเป็นต่อการให้บริการและปฏิบัติตามกฎหมาย เมื่อผู้ใช้ขอลบบัญชี ผู้ดูแลจะดำเนินการลบหรือทำให้ไม่สามารถระบุตัวบุคคลได้เมื่อพ้นความจำเป็น ทั้งนี้ข้อมูลที่บันทึกไว้ในเบราว์เซอร์สามารถลบได้โดยล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ ส่วนบันทึกทางเทคนิคอาจมีระยะเวลาเก็บตามผู้ให้บริการโฮสติ้งและ Supabase

6. สิทธิของผู้ใช้

ผู้ใช้อาจขอเข้าถึง สำเนา แก้ไข ลบ หรือจำกัดการใช้ข้อมูล คัดค้านการประมวลผล หรือถอนความยินยอมในกรณีที่ใช้ความยินยอมเป็นฐาน โดยติดต่อผู้ดูแลผ่านช่องทางในข้อ 1 ผู้ใช้อาจลบบัญชีผ่านผู้ให้บริการยืนยันตัวตนหรือขอให้ผู้ดูแลดำเนินการ เว็บต้นแบบนี้ยังไม่มีปุ่มลบบัญชีในหน้าเว็บ

7. ความปลอดภัยและการเปลี่ยนแปลง

มีการจำกัดการเรียกข้อมูลตลาดและข่าวไว้สำหรับเซสชันที่ยืนยันแล้ว และใช้การเชื่อมต่อ HTTPS เมื่อเปิดผ่าน Render อย่างไรก็ตามไม่สามารถรับประกันความปลอดภัยได้สมบูรณ์ ผู้ดูแลจะปรับปรุงนโยบายเมื่อวิธีใช้ข้อมูลเปลี่ยน โดยแสดงวันที่แก้ไขไว้ด้านบน

นโยบายฉบับนี้เป็นร่างที่อิงฟังก์ชันปัจจุบัน ผู้ดูแลต้องใส่ชื่อ/ช่องทางติดต่อจริง ตรวจสอบภูมิภาคและการตั้งค่าการเก็บ log ของผู้ให้บริการ รวมถึงทบทวนเนื้อหาก่อนใช้งานเชิงพาณิชย์หรือเปิดรับสมาชิกทั่วไป
